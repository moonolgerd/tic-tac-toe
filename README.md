# Tic Tac Toe 🎮

A clean, animated, browser-based **Tic Tac Toe** game — no frameworks, no dependencies. Just HTML, CSS, and vanilla JavaScript.

## Features

- 🎯 Two-player local gameplay (X vs O)
- 🏆 Persistent score tracking across rounds (X wins / O wins / Draws)
- ✨ Pop-in animation when placing a mark
- 💡 Winning cells pulse to highlight the result
- 🌟 Stylish end-of-round overlay
- 📱 Responsive layout (works on mobile)
- 🔄 **Restart Game** — resets the board, keeps scores
- 🗑️ **Reset Scores** — wipes the scoreboard and restarts

## How to Play

1. Open `index.html` in any modern browser — nothing to install.
2. Players take turns clicking a cell.
3. First player to get **3 in a row** (horizontal, vertical, or diagonal) wins.
4. If all 9 squares are filled with no winner, it's a **draw**.
5. Hit **Play Again** (or **Restart Game**) to start the next round.
